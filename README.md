# PelmenysSecret — исходный код (read‑only)
A wonderful adventure-game about a boy and his love. And btw, what is secret of PELMENY???

Этот репозиторий содержит исходный код игры. Он выложен **только для ознакомления**.

## Правила использования

✅ Что можно:
- Смотреть и изучать код
- Скачивать архив репозитория
- Делать форк (но без изменения кода)
- Цитировать код с указанием авторства

❌ Что нельзя:
- Менять исходный код без моего разрешения
- Использовать код в коммерческих целях
- Распространять модифицированные версии кода
- Пытаться декомпилировать или взламывать игру

## Пользовательские уровни

В игре есть редактор уровней. Вы можете создавать свои карты и распространять их **бесплатно** при соблюдении условий:
- Не продавать уровни и ассеты к ним
- Не использовать уровни в коммерческих проектах
- При распространении указывать автора уровня

## Стримы и летсплеи

Стримить игру, записывать летсплеи и монетизировать их на YouTube/Twitch **разрешено**.
